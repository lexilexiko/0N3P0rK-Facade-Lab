# ФасадЛаб

Настольный редактор для Windows. В проект входят переносимая версия без установки и установщик.

## Быстрый запуск

Запустите **ФасадЛаб-0.6.5-x64.exe** из папки `release`. Устанавливать Node.js или другие программы не нужно. При запуске появится локальный экран входа; пароль `L3xik0`. Это только экран блокировки, а не шифрование: данные приложения доступны текущему пользователю Windows.

## Что можно проверить

- Фасад с тремя габаритами: ширина, высота и толщина; фрезеровка основного контура и отдельные настройки фрезы для каждого вложенного вектора. Выберите редактируемый вектор в правой панели; разрез одновременно показывает все векторы с обеих сторон фасада, в масштабе и с миллиметровой сеткой.
- Профиль из отдельных векторов: для каждого задаются сторона, отступ от края, своя фреза, ширина и глубина реза. Можно добавлять проходы с разными фрезами и глубиной.
- Фасад-гребёнку: направление проходов, шаг, начальный и конечный отступы, тип и диаметр фрезы, глубина. Проходы сохраняют строгий шаг; независимые флажки добавляют проход за началом и концом заготовки, не перераспределяя основной шаг. Координаты проходов совпадают в видах, карте раскроя и DXF.
- Локальный каталог собственных фрез с названием, формой эскиза и диаметром/шириной. Форма сохраняется на этом компьютере и доступна в настройках векторов.
- Импорт библиотеки инструментов ArtCAM из одного или нескольких файлов `.TDB`: распознаются названия и размеры, указанные в имени, повторы пропускаются, а фреза получает упрощённую форму эскиза. Записи без подходящего размера пропускаются; реальные профили фрез, режимы резания и точность эскиза импорт не гарантируются.
- Локальный список изделий с автосохранением: переключайтесь между фасадами, профилями и гребёнками; ненужное изделие можно удалить с подтверждением. Заказ раскроя хранится отдельно и не исчезает при выборе или создании другого изделия.
- Карта раскроя заказа: добавляйте фасады, профили и гребёнки вместе с количеством, задавайте размер листа, толщину, краевой отступ и зазор. Детали автоматически раскладываются с поворотом на 90°; программа сообщает о несовпадении толщины и непоместившихся деталях. DXF-карта содержит лист, границы деталей и вычисленные проходы профиля/гребёнки.
- Шаблоны векторов сохраняются на этом компьютере, масштабируются с сохранением пропорций и проверяются на возможность размещения; неподходящий размер сопровождается сообщением. Шаблоны можно удалить с подтверждением.
- Быстрый отступ для нового вектора и отдельная кнопка создания вектора, масштабирование и перемещение чертежа мышью, выбор верхней фактуры фасада (скетч, МДФ, шпон или однотонная заливка) без изменения рисунка векторов, сдержанные графитовые карандашные траектории с лёгкой штриховкой канавок фрез, сворачиваемая панель слоёв, проекты JSON, импорт SVG и экспорт DXF/SVG.
- Переключение вида сверху, разреза и карты листа в шапке; настройки выбранного вектора доступны только в редакторе фасада, параметры проходов — только для профиля и гребёнки, а настройки карты раскроя — только в карте листа. Выбор типа нового изделия размещён рядом с компактной кнопкой создания.
- Импорт ASCII DXF: поддерживаются LINE, LWPOLYLINE и POLYLINE с дуговыми сегментами, ARC, CIRCLE, ELLIPSE, SPLINE, POINT, SOLID, 3DFACE и INSERT-вставки блоков. Кривые преобразуются в плотные линейные сегменты; размеры координат трактуются как миллиметры. Текстовые и аннотационные объекты не являются траекториями; другие непреобразованные типы явно указываются после импорта.
- Скруглённые наружу и внутрь углы вложенных прямоугольных векторов. Каталог фрез можно редактировать и удалять; ArtCAM `.TDB` по-прежнему импортируется отдельной кнопкой.
- В окне «О программе»: программист L3xik0, дополнительный агент Евгений Жуков.

3D-предпросмотр удалён. DXF для гребёнки и профиля содержит вычисленные траектории и габарит заготовки, но не режимы резания или компенсацию инструмента. Разрез и форма пользовательской фрезы — эскизы; сверьте их с реальной оснасткой, проверьте DXF в ArtCAM и выполните пробную обработку до запуска детали.

## Разработка и сборка

Установите Node.js LTS, выполните `npm install`, затем `npm start`.

- `npm run portable` — переносимый EXE для Windows x64.
- `npm run dist` — EXE-установщик.
