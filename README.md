# ФасадЛаб

Настольный редактор для Windows. В проект входят переносимая версия без установки и установщик.

## Быстрый запуск

Запустите переносимый EXE **ФасадЛаб-0.7.0-x64-portable.exe** или **ФасадЛаб-0.7.0-ia32-portable.exe** из папки `release`. Устанавливать Node.js или другие программы не нужно. Вход по паролю временно отключён.

Для 32-разрядной Windows переносимую версию собирает `npm run portable:ia32`, а отдельный установщик — `npm run dist:ia32`. Используется Electron 32.3.3, последняя ветка Electron с 32-bit Windows runtime. Этот runtime рассчитан на Windows 10 и новее; Windows 7/8 не поддерживаются.

## Что можно проверить

- Фасад с тремя габаритами: ширина, высота и толщина; фрезеровка основного контура и отдельные настройки фрезы для каждого вложенного вектора. Выберите редактируемый вектор в правой панели; разрез одновременно показывает все векторы с обеих сторон фасада, в масштабе и с миллиметровой сеткой.
- Профиль из отдельных векторов: компактный список и направление находятся слева, там же можно задать точный отступ от края для следующего нового вектора. Справа отображаются настройки только выбранного вектора: сторона, отступ, своя фреза, ширина и глубина реза.
- Фасад-гребёнку: направление проходов, шаг, начальный и конечный отступы, тип и диаметр фрезы, глубина. Основные проходы идут от начального отступа с заданным шагом до последней позиции, которая не выходит за конечный отступ; дополнительные флажки продолжают ряд ровно на один шаг до первого и после последнего прохода. Например, при размере 100 мм и шаге 10 мм без отступов ряд идёт от 0 до 100 мм, а дополнительные проходы — на -10 и 110 мм. При отступах 10/10 мм основные проходы идут от 10 до 90 мм, дополнительные — на 0 и 100 мм. Виды, разрез, карта раскроя и DXF используют общие позиции проходов.
- Отдельная библиотека фрез открывается кнопкой «Фрезы» в шапке; в ней остаются стандартные типы и каталог фрез, импортированных из ArtCAM `.TDB`, с возможностью редактировать импортированные записи. Создавать фрезу вручную по условной форме нельзя. В настройках вектора разрез паза строится с его шириной и глубиной по той же геометрии, что и основной чертёж сечения; отдельный условный силуэт фрезы не используется.
- Импорт библиотеки инструментов ArtCAM из одного или нескольких файлов `.TDB`: распознаются названия и размеры, указанные в имени, повторы пропускаются, а фреза получает упрощённую форму эскиза. Записи без подходящего размера пропускаются; реальные профили фрез, режимы резания и точность эскиза импорт не гарантируются.
- Локальный список изделий с автосохранением: переключайтесь между фасадами, профилями и гребёнками; ненужное изделие можно удалить с подтверждением. Заказ раскроя хранится отдельно и не исчезает при выборе или создании другого изделия.
- Карта раскроя заказа: добавляйте фасады, профили и гребёнки вместе с количеством, задавайте размер листа, толщину, краевой отступ и зазор. Детали автоматически раскладываются с поворотом на 90°; программа сообщает о несовпадении толщины и непоместившихся деталях. DXF-карта содержит лист, границы деталей и вычисленные проходы профиля/гребёнки.
- Шаблоны фасадов, профилей и гребёнок открываются отдельной кнопкой «Стили», сохраняются на этом компьютере, проверяются на возможность применения и удаляются с подтверждением.
- Кнопка «Документ / PDF» открывает печать чертежа и отдельного листа спецификации. В окне печати Windows выберите принтер или «Microsoft Print to PDF»; длинная таблица спецификации продолжается на следующих страницах, не уменьшая чертёж.
- Быстрый отступ и выбор родительского вектора расположены рядом с кнопкой создания. Фасад и созданные контуры выбираются в левом списке; там же можно удалить отдельный контур и вложенные в него контуры. Справа показаны только настройки выбранного контура. Масштабирование и перемещение чертежа мышью работают также в разрезе; при перетаскивании текст интерфейса не выделяется. Разрез имеет миллиметровую сетку (клетка 10 мм, усиленная линия через 50 мм), масштабную линейку и компактную спецификацию. Выбор верхней фактуры фасада (скетч, МДФ, шпон или однотонная заливка) не меняет рисунок векторов; также доступны сдержанные графитовые карандашные траектории с лёгкой штриховкой канавок фрез, сворачиваемая панель слоёв, проекты JSON, импорт SVG и экспорт DXF/SVG.
- Переключение вида сверху, разреза и карты листа в шапке; настройки выбранного вектора доступны только в редакторе фасада, параметры проходов — только для профиля и гребёнки, а настройки карты раскроя — только в карте листа. Выбор типа нового изделия размещён рядом с компактной кнопкой создания.
- Импорт ASCII DXF: поддерживаются LINE, LWPOLYLINE и POLYLINE с дуговыми сегментами, ARC, CIRCLE, ELLIPSE, SPLINE, POINT, SOLID, 3DFACE и INSERT-вставки блоков. Кривые преобразуются в плотные линейные сегменты; размеры координат трактуются как миллиметры. Текстовые и аннотационные объекты не являются траекториями; другие непреобразованные типы явно указываются после импорта.
- Скруглённые наружу и внутрь углы вложенных прямоугольных векторов. Каталог фрез можно редактировать и удалять; ArtCAM `.TDB` по-прежнему импортируется отдельной кнопкой.
- В окне «О программе»: программист L3xik0, дополнительный агент Евгений Жуков.

3D-предпросмотр удалён. DXF для гребёнки и профиля содержит вычисленные траектории и габарит заготовки, но не режимы резания или компенсацию инструмента. Разрез и форма пользовательской фрезы — эскизы; сверьте их с реальной оснасткой, проверьте DXF в ArtCAM и выполните пробную обработку до запуска детали.

## Разработка и сборка

Установите Node.js LTS, выполните `npm install`, затем `npm start`.

- `npm run portable` — переносимый EXE для Windows x64 (имя с суффиксом `-portable`).
- `npm run dist` — EXE-установщик для Windows x64.
- `npm run portable:ia32` — переносимый EXE для 32-bit Windows 10+ (Electron 32.3.3).
- `npm run dist:ia32` — EXE-установщик для 32-bit Windows 10+ (Electron 32.3.3).
