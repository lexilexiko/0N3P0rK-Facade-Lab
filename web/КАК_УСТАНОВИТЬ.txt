ФасадЛаб как приложение для Android (PWA)

Что внутри
  index.html            — программа (то же, что fasadlab_prototype.html + подключение PWA)
  manifest.webmanifest  — название, иконки, цвета приложения
  sw.js                 — работа без интернета (кэш)
  icons/                — иконки 192, 512 и maskable 512

Как поставить на телефон (1 раз)
  1. Выложите ВСЮ эту папку на любой хостинг с HTTPS, например:
       - GitHub Pages (Settings -> Pages),
       - Netlify (перетащить папку на netlify.com/drop),
       - Cloudflare Pages.
     С file:// и с обычного http:// установка не работает (кроме localhost).
  2. Откройте адрес в Chrome на Android.
  3. Меню ⋮ -> «Установить приложение» (или «Добавить на главный экран»).
  4. Появится иконка «ФасадЛаб». Запускается без адресной строки, работает без интернета.

Как получить настоящий APK-файл
  Когда папка уже лежит на хостинге: зайдите на pwabuilder.com, вставьте адрес,
  выберите Android -> Download. Сервис выдаст готовый подписанный APK/AAB
  (его можно ставить напрямую или загрузить в Google Play).

Обновление
  Замените файлы на хостинге. При смене index.html поменяйте номер в sw.js
  (const CACHE='fasadlab-v2' -> 'fasadlab-v3'), чтобы телефон подтянул новую версию.

Заметки
  - Экспорт DXF/PDF/SVG сохраняется в «Загрузки» телефона как в обычном Chrome.
  - Интерфейс рассчитан на планшет и широкий экран; на телефоне удобнее в
    альбомной ориентации. Страницу можно масштабировать щипком.
